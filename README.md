# Cocktail Rush 🍸

Jeu de rapidité multijoueur pour réviser les fiches techniques cocktails (EBS, chapitre 22 — 47 recettes).

- Une table de jeu, chacun sur son téléphone : l'hôte ouvre une table et donne le code à 4 lettres.
- Un cocktail est tiré, chacun écrit de mémoire : verre, glaçons, technique, ingrédients + dose, décoration.
- La carte est posée face cachée devant sa place, puis toutes les cartes sont retournées en même temps.
- Moins d'erreurs d'abord, puis le plus rapide : 4·3·2·1 pts à 4 joueurs, +2 pour une carte parfaite.

Correction tolérante : français ou anglais, petites fautes, `cl` accepté, `top` = `fill`.

## Jouer
Ouvrir la page GitHub Pages du dépôt. Les téléphones se connectent entre eux en pair-à-pair (PeerJS), sans compte.

Un seul fichier : `index.html`. Les recettes sont dans le tableau `C` en haut du script.
